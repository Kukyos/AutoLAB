FRONTEND 1-2 MARK PLAYGROUND

Open index.html in a browser.

Each page is executable:
- javascript.html: JS syntax, objects, arrays, functions, JSON, if/else, confirm
- jquery.html: selectors, val, text, hide/show/toggle, addClass, click, calculator
- css.html: selectors, box model, fixed positioning, z-index, text-decoration
- html.html: lists, image, forms, radio/checkbox, file, tables, semantic elements
- bootstrap.html: Bootstrap alert/button classes

For jQuery and Bootstrap examples, internet access is needed because the pages load their libraries from CDNs.

Tip:
Use F12 -> Console while on javascript.html to see console.log() output.
